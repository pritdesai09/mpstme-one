# MPSTME ONE

AI-powered campus assistant for NMIMS MPSTME — a RAG chatbot over the
college website and Student Resource Book, powered by Gemini and deployed on Azure.

## Stack
- Backend: FastAPI + LangGraph + Gemini API
- Vector store: PostgreSQL + pgvector
- Frontend: React + Vite + Tailwind
- Hosting: Azure Container Apps + Static Web Apps
